# Lab4Web — Layout Sederhana

Repository ini berisi hasil Praktikum 4 Pemrograman Web. Praktikum mencakup latihan box element menggunakan CSS, pembuatan layout sederhana, navigasi, serta pengembangan halaman About dan Kontak.

## Tujuan Praktikum

- Memahami penggunaan CSS untuk mengatur layout elemen HTML.
- Mengenal penggunaan `float` dan `clear` pada latihan box element.
- Membuat layout halaman yang terdiri dari header, navigasi, hero, konten, sidebar, dan footer.
- Membuat halaman About yang memuat deskripsi dan portofolio.
- Membuat halaman Kontak dengan formulir nama, email, dan pesan.
- Mendokumentasikan hasil praktikum menggunakan screenshot.

## Teknologi

- HTML5
- CSS3
- Visual Studio Code
- Browser

## Kesimpulan

Praktikum ini menunjukkan bagaimana HTML membentuk struktur halaman, sedangkan CSS mengatur tata letak dan tampilannya. Latihan box element memperkenalkan penggunaan `float` dan `clear`. Selanjutnya, layout sederhana dikembangkan menjadi halaman Home, Artikel, About, dan Kontak dengan navigasi serta formulir kontak.
